# Sounds

Original duck sounds, synthesised for Duckherd and released under the MIT license.

| File | Plays when |
| --- | --- |
| `quack.wav` | the lead duck finishes a long turn |
| `chirp.wav` | something needs you |

`honk.wav` and `snore.wav` are not played at the moment. `/crew quiet` plays the sounds softly, `/crew off` turns them off.
